## Proposed Reusable Icon-Action Categories

- Review / Orient: Read, align, introduce, or inspect existing context before work starts. Examples: Introduction, Review Evidence, Review Opportunities.
- Capture / Generate: Create raw inputs, responses, statements, metrics, or opportunities. Examples: Capture Problems, Generate Metrics, Generate HMWs.
- Cluster: Group related inputs into themes or meaningful sets. Examples: Cluster Objectives, Cluster Problems, Cluster Responses.
- Draft / Refine: Turn raw material into clearer options or improve existing candidates. Examples: Draft Statements, Refine Opportunities, Refine Themes.
- Map / Evaluate: Place options on a matrix or evaluate them against criteria. Examples: Set Up Matrix, Map Opportunities, Map Priorities.
- Select / Decide: Choose, confirm, prioritise, or commit to a decision. Examples: Select Priorities, Select Opportunities, Confirm Choices.
- Ask Why: Iterate through causal questioning while preserving separate executable steps. Examples: Why #1, Why #2, Why #5.
- Commit / Action: Translate outcomes into next steps, actions, or commitment. Examples: Commit Actions, Define Next Steps, Review & Commit.
