# PlayBooky V3 Documentation

This folder is the source of truth for PlayBooky V3 documentation. Its structure mirrors the Design Portal navigation, the repository architecture, and the mental model of the PlayBooky Design System.

## Sections

- `01-foundation/` defines the project constitution, principles, and AI behaviour expectations.
- `02-design-system/` defines the Design Portal information architecture and documentation standards.
- `03-foundations/` defines foundational design tokens and visual rules.
- `04-layout/` defines page, grid, container, section, stack, and surface rules.
- `05-components/` defines approved component categories and future component documentation.
- `06-patterns/` defines reusable product and system patterns.
- `07-assets/` defines asset library governance.
- `08-ai/` defines AI build, review, and quality gate rules.
- `09-product/` defines product vision and roadmap placeholders.
