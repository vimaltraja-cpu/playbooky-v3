# Workshop OS - Architecture V3

## Vision

Workshop OS is an AI Workshop Designer.

Users do not select workshops, frameworks, or activities.

Users describe their challenge, desired outcome, and constraints.

Workshop OS diagnoses the situation, identifies the current stage of thinking, selects appropriate workshop activities, and generates a bespoke workshop designed specifically for the user's context.

The goal is to help teams move from uncertainty to action through intelligently designed workshops.

---

# Core Principle

Workshop OS does not recommend workshops.

Workshop OS designs workshops.

Every generated workshop should be tailored to:

- The challenge being solved
- The current state of understanding
- The desired outcome
- Available time
- Number of participants
- Stakeholder involvement
- Remote or in-person delivery

# Diagnosis Engine

The diagnosis engine determines where the team currently is and where they need to go.

It analyses:

## Challenge

What challenge are you trying to solve?

Examples:

- User drop-off
- Stakeholder misalignment
- Prioritisation
- Product strategy
- Process improvement

## Current State

What do you already know?

Examples:

- Research completed
- Research not started
- Ideas already identified
- Opportunities already known
- Decisions still required

## Desired Outcome

What do you need at the end of the workshop?

Examples:

- Shared understanding
- Prioritised opportunities
- Clear decision
- Action plan
- Defined scope

## Constraints

Examples:

- Workshop duration
- Participant count
- Remote or in-person
- Stakeholder involvement
- Cross-functional attendance

---

# Stages

Stages represent the current thinking mode of the team.

The diagnosis engine identifies a Primary Stage and Secondary Stage.

## Goals

Question being answered:

What are we trying to achieve?

Signals:

- No shared vision
- No shared objectives
- No success criteria
- Conflicting priorities

---

## Understand

Question being answered:

What is really happening?

Signals:

- Need research
- Need evidence
- Need user understanding
- Need process understanding
- High uncertainty

---

## Frame

Question being answered:

How should we define the challenge?

Signals:

- Problem unclear
- Problem too broad
- Multiple interpretations
- No agreed problem statement

---

## Ideas

Question being answered:

What could we do?

Signals:

- Need solutions
- Need concepts
- Need options
- Need innovation

---

## Evaluate

Question being answered:

Which options are strongest?

Signals:

- Too many opportunities
- Too many ideas
- Need prioritisation
- Need trade-off decisions

---

## Decide

Question being answered:

What should we commit to?

Signals:

- Need ownership
- Need action plan
- Need roadmap
- Need commitment

---

## Discuss

Question being answered:

How do we align perspectives?

Signals:

- Stakeholder disagreement
- Misalignment
- Communication issues
- Political tension

# Techniques

Techniques are facilitation patterns that can be applied across multiple activities.

Examples:

- Blind Vote
- Theme Sort
- Dot Vote
- Parking Lot
- Ice Breakers
- Session Principles
- T-Bar Format
- Meeting Wizard

Techniques support activities but are not activities themselves.

---

# Activity Selection Engine

The Activity Selection Engine dynamically builds workshops using:

- Primary Stage
- Secondary Stage
- Desired Outcome
- Workshop Duration
- Participant Count
- Constraints

Activities are selected based on relevance rather than predefined templates.

---

# Workshop Design Engine

The Workshop Design Engine creates a bespoke agenda.

Example:

Input:

Research completed.

20 opportunities identified.

Need prioritisation.

Need stakeholder alignment.

90-minute workshop.

Output:

10 mins Context Review

15 mins Opportunity Clustering

20 mins Impact Assessment

15 mins Effort Assessment

15 mins Priority Mapping

15 mins Decision & Action Planning

The workshop is assembled dynamically rather than selected from a template.

---

# FigJam Generation

For each selected activity Workshop OS generates:

- Activity Instructions
- Board Layout
- Facilitation Notes
- Copy-to-Clipboard FigJam Prompt

Users can generate each board section individually using FigJam AI.

---

# Facilitation Guide

Workshop OS generates:

- Workshop Overview
- Running Order
- Activity Instructions
- Timing Guidance
- Facilitation Notes

---

# Synthesis Guide

Workshop OS generates:

- Analysis Instructions
- Synthesis Prompts
- Recommendation Prompts
- Action Planning Prompts

This enables workshop outputs to be converted into decisions and actions.

---

# North Star

Workshop OS is not a workshop template library.

Workshop OS is an AI Workshop Designer that diagnoses challenges and generates bespoke workshops using modular activities, techniques, and facilitation patterns.
