# SWOT Analysis

Best Used When: The team needs structured evaluation of a challenge, opportunity or strategy.
Duration: 90 mins
Facilitator Notes: Keep discussions balanced across all four areas.

Avoid spending too much time debating individual items.

Focus on identifying patterns and strategic implications.
Inputs Required: Ideas, Problem statement, Stakeholders
Instructions: 1. Create four sections: Strengths, Weaknesses, Opportunities and Threats.

2. Generate ideas individually.

3. Add ideas to the relevant section.

4. Discuss and refine contributions.

5. Identify key themes.

6. Agree on implications and next steps.
Layout Type: Matrix
Outputs Produced: Decision, Insights
Purpose: Assess strengths, weaknesses, opportunities and threats.
Remote Friendly: Yes
Stage: Evaluate
