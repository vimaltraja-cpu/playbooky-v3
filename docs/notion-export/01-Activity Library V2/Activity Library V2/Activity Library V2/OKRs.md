# OKRs

Best Used When: The team lacks focus, has unclear goals, or needs measurable success criteria.
Duration: 60 mins
Facilitator Notes: Encourage ambitious but realistic objectives.

Avoid creating multiple competing objectives.

Focus discussion on outcomes rather than outputs.

Ensure key results are measurable and time-bound.
Inputs Required: Business goal, Team context
Instructions: 1. Define the objective the team wants to achieve.

2. Generate potential objectives individually.

3. Discuss and refine options.

4. Agree on a single objective.

5. Brainstorm measurable indicators of success.

6. Select the most important metrics.

7. Convert metrics into specific key results.

8. Agree ownership and review cadence.
Layout Type: Columns
Outputs Produced: Action plan, Shared goal
Purpose: Help a team define a shared objective and measurable key results.
Remote Friendly: Yes
Stage: Goals
