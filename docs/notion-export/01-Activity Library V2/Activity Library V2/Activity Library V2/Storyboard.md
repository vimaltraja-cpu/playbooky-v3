# Storyboard

Best Used When: The team wants to explore and communicate end-to-end solution ideas.
Duration: 90 mins
Facilitator Notes: Keep participants focused on the experience rather than detailed UI solutions.

Encourage discussion around assumptions and risks.

Use the storyboard as a conversation tool rather than an artefact to perfect.
Inputs Required: Ideas, Problem statement, User feedback
Instructions: 1. Define the scenario being explored.

2. Break the experience into key stages.

3. Sketch or describe what happens at each stage.

4. Focus on user actions, thoughts and outcomes.

5. Discuss gaps, opportunities and assumptions.

6. Capture insights for further development.
Layout Type: Timeline
Outputs Produced: Ideas
Purpose: Visualise future experiences, concepts or service journeys.
Remote Friendly: Yes
Stage: Ideas
