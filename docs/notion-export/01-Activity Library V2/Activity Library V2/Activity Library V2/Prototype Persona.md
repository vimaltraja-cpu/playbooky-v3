# Prototype Persona

Best Used When: Research is limited but the team needs a shared understanding of users.
Duration: 60 mins
Facilitator Notes: Make it clear that the persona is a working hypothesis.

Avoid creating overly detailed fictional profiles.

Focus on creating shared understanding rather than perfection.
Inputs Required: Existing research, User feedback
Instructions: 1. Define the audience being explored.

2. Capture known characteristics.

3. Discuss goals, needs and behaviours.

4. Identify frustrations and motivations.

5. Create a shared persona profile.

6. Highlight assumptions that need validation.
Layout Type: Canvas
Outputs Produced: Insights
Purpose: Create provisional user personas from existing knowledge.
Remote Friendly: Yes
Stage: Understand
