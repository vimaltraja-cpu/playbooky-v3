# How Might We

Best Used When: The team understands the problem and needs to create useful opportunity statements.
Duration: 60 mins
Facilitator Notes: Encourage open-ended questions.

Avoid leading questions that imply a solution.

Focus on creating opportunity spaces rather than constraints.
Inputs Required: Insights, Problem statement
Instructions: 1. Present available evidence and findings.

2. Discuss observations and patterns.

3. Capture possible problem statements.

4. Refine statements collaboratively.

5. Challenge assumptions and ambiguity.

6. Agree a clear and concise problem statement.

7. Validate that everyone understands it.
Layout Type: Rows
Outputs Produced: Ideas, Problem statement
Purpose: Reframe problems into opportunity-focused prompts for ideation.
Remote Friendly: Yes
Stage: Frame
