# Mad Sad Glad

Best Used When: The team needs reflection, retrospectives or emotional insight.
Duration: 60 mins
Facilitator Notes: Create psychological safety.

Encourage honesty.

Focus on understanding experiences rather than defending decisions.

Look for recurring patterns.
Inputs Required: Stakeholders, Team context
Instructions: 1. Create three columns: Mad, Sad and Glad.

2. Ask participants to reflect individually.

3. Capture responses in the relevant column.

4. Discuss recurring themes.

5. Identify opportunities for improvement.

6. Agree actions where appropriate.
Layout Type: Columns
Outputs Produced: Alignment, Insights
Purpose: Explore emotional responses to a project, initiative or experience.
Remote Friendly: Yes
Stage: Discuss
