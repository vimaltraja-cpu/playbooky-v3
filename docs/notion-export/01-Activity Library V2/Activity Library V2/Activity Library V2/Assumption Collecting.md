# Assumption Collecting

Best Used When: The team suspects decisions are being driven by opinion rather than evidence.
Duration: 60 mins
Facilitator Notes: Create a safe environment for participants to challenge existing thinking.

Distinguish assumptions from facts.

Prioritise assumptions that carry the greatest risk.
Inputs Required: Team context
Instructions: 1. Present the challenge being explored.

2. Ask participants to write down assumptions.

3. Share assumptions with the group.

4. Cluster similar assumptions together.

5. Discuss which assumptions are most critical.

6. Identify assumptions that require validation.
Layout Type: Columns
Outputs Produced: Insights, Risks
Purpose: Identify assumptions influencing decisions.
Remote Friendly: Yes
Stage: Understand
