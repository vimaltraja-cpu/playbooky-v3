# Roles & Responsibilities

Best Used When: Ownership or accountability is unclear.
Duration: 60 mins
Facilitator Notes: Keep the discussion objective and focused on clarity.

Avoid turning the session into a performance review.

Focus on improving collaboration and accountability.
Inputs Required: Stakeholders, Team context
Instructions: 1. List all key roles involved.

2. Capture current responsibilities.

3. Identify overlaps and gaps.

4. Discuss areas of confusion.

5. Agree ownership for critical activities.

6. Document decisions and actions.
Layout Type: Matrix
Outputs Produced: Alignment, Decision
Purpose: Clarify ownership and responsibilities across teams.
Remote Friendly: Yes
Stage: Understand
