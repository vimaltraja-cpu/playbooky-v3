# Newspaper Headline

Best Used When: The team needs a shared vision of success.
Duration: 60 mins
Facilitator Notes: Encourage ambitious thinking.

Avoid discussing constraints too early.

Use the headlines to create a shared picture of success.
Inputs Required: Business goal
Instructions: 1. Ask participants to imagine a future newspaper article celebrating success.

2. Individually create headlines.

3. Share and discuss headlines.

4. Identify common themes.

5. Create a combined vision statement.

6. Capture the measures of success required to achieve it.
Layout Type: Canvas
Outputs Produced: Alignment, Shared goal
Purpose: Define future success by imagining a positive headline about the outcome.
Remote Friendly: Yes
Stage: Goals
