# Sticky Steps

Best Used When: The team knows the goal but needs a practical path forward.
Duration: 30 mins
Facilitator Notes: Encourage participants to think in small achievable steps.

Challenge large vague actions.

Focus on creating momentum and clarity.
Inputs Required: Business goal
Instructions: 1. Define the goal or outcome.

2. Individually generate the steps required to achieve it.

3. Place each step on a sticky note.

4. Arrange steps into a logical sequence.

5. Identify dependencies and risks.

6. Agree on immediate next actions.
Layout Type: Timeline
Outputs Produced: Action plan
Purpose: Break a goal into small achievable steps.
Remote Friendly: Yes
Stage: Goals
