# Problem Statement

Best Used When: The team has different interpretations of the problem or the challenge feels too broad.
Duration: 60 mins
Facilitator Notes: Prevent participants from jumping to solutions.

Focus on the problem itself.

Keep statements specific and evidence-based.

Challenge vague language.
Inputs Required: Existing research, Problem statement, User feedback
Outputs Produced: Alignment, Problem statement
Purpose: Turn a broad or unclear challenge into a focused problem statement.
Remote Friendly: Yes
Stage: Frame
