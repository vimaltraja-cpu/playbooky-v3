# Reverse Brainstorm

Best Used When: The team feels stuck, is suffering from groupthink, or keeps generating similar ideas.
Duration: 60 mins
Facilitator Notes: This works best when teams are stuck or repeating the same ideas.

Encourage humour and exaggeration.

The value comes from reversing the negative ideas.
Inputs Required: Problem statement, Team context
Outputs Produced: Ideas
Purpose: Generate solutions by exploring how to make the problem worse first.
Remote Friendly: Yes
Stage: Ideas
