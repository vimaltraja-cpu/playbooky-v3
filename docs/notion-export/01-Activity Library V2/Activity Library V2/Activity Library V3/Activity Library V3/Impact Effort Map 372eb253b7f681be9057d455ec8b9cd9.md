# Impact Effort Map

Best Used When: The team has several options and needs to prioritise.
Duration: 30 mins
Facilitator Notes: Focus on relative comparison rather than precise scoring.

Challenge assumptions around effort and impact.

Look for opportunities to create alignment across the group.
Inputs Required: Ideas, Opportunities
Outputs Produced: Decision, Prioritised list
Purpose: Compare ideas or opportunities based on expected impact and effort.
Remote Friendly: Yes
Stage: Evaluate
