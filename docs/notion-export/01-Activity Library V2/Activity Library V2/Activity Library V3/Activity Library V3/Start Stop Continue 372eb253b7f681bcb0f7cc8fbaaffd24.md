# Start Stop Continue

Best Used When: The team needs alignment, reflection or agreement on future ways of working.
Duration: 60 mins
Facilitator Notes: Keep the discussion constructive.

Avoid personal criticism.

Focus on behaviours, processes and ways of working rather than individuals.

Push for actionable outcomes.
Inputs Required: Stakeholders, Team context
Outputs Produced: Action plan, Alignment
Purpose: Create alignment by identifying behaviours, activities or processes the team should start, stop or continue.
Remote Friendly: Yes
Stage: Decide
