# Premortem

Best Used When: The team wants to reduce risk and improve decision quality.
Duration: 60 mins
Facilitator Notes: Create psychological safety.

Encourage participants to surface uncomfortable truths.

Avoid turning the session into a solution workshop too early.
Inputs Required: Ideas, Opportunities, Stakeholders
Outputs Produced: Decision, Risks
Purpose: Identify potential risks before implementation begins.
Remote Friendly: Yes
Stage: Evaluate
