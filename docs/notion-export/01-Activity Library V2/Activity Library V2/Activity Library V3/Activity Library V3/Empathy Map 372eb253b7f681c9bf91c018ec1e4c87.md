# Empathy Map

Best Used When: The team needs deeper understanding of users.
Duration: 60 mins
Facilitator Notes: Encourage participants to use evidence rather than assumptions.

Keep the discussion focused on the user rather than business needs.

Challenge unsupported statements.
Inputs Required: Existing research, User feedback
Outputs Produced: Insights
Purpose: Explore what users think, feel, see and do.
Remote Friendly: Yes
Stage: Understand
