# Round Robin

Best Used When: You want contributions from every participant and need to avoid dominant voices.
Duration: 30 mins
Facilitator Notes: Ensure equal participation.

Prevent dominant voices from taking over.

Keep the pace moving.

Focus on idea generation rather than evaluation.
Inputs Required: Problem statement, Team context
Outputs Produced: Ideas
Purpose: Generate ideas collaboratively while ensuring equal participation.
Remote Friendly: Yes
Stage: Ideas
