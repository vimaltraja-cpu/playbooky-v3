# Sailboat

Best Used When: The team needs alignment around goals and obstacles.
Duration: 60 mins
Facilitator Notes: Use the visual metaphor to encourage participation.

Ensure both positive and negative factors are explored.

Focus on practical actions that can be taken after the workshop.
Inputs Required: Business goal, Team context
Outputs Produced: Alignment, Risks, Shared goal
Purpose: Explore goals, risks, blockers and opportunities using a visual metaphor.
Remote Friendly: Yes
Stage: Goals
