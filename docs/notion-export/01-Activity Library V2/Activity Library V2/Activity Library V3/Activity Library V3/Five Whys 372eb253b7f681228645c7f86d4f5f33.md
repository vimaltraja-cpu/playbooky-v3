# Five Whys

Best Used When: The team sees symptoms but does not yet understand the underlying cause.
Duration: 30 mins
Facilitator Notes: Do not force exactly five iterations.

Stop when the conversation reaches a meaningful root cause.

Avoid blaming people.

Focus on systems, behaviours and contributing factors.
Inputs Required: Problem statement
Outputs Produced: Insights
Purpose: Explore root causes by repeatedly asking why a problem is happening.
Remote Friendly: Yes
Stage: Understand
