# Newspaper Headline

Best Used When: The team needs a shared vision of success.
Duration: 60 mins
Facilitator Notes: Encourage ambitious thinking.

Avoid discussing constraints too early.

Use the headlines to create a shared picture of success.
Inputs Required: Business goal
Outputs Produced: Alignment, Shared goal
Purpose: Define future success by imagining a positive headline about the outcome.
Remote Friendly: Yes
Stage: Goals
