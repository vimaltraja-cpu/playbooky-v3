# Crazy Eights

Best Used When: The team needs options, concepts, or alternative approaches.
Duration: 30 mins
Facilitator Notes: Emphasise speed over quality.

Encourage participants to avoid self-editing.

The goal is variety and exploration rather than polished ideas.
Inputs Required: Opportunities, Problem statement
Outputs Produced: Ideas
Purpose: Generate a range of solution ideas quickly.
Remote Friendly: Yes
Stage: Ideas
