# Democratic Discussion

Best Used When: The team needs broad participation and collective ownership of outcomes.
Duration: 60 mins
Facilitator Notes: Protect equal participation.

Watch for dominant personalities.

Encourage quieter participants to contribute.

Focus on shared understanding.
Inputs Required: Stakeholders, Team context
Outputs Produced: Alignment, Decision
Purpose: Create equal opportunity for participation and decision making.
Remote Friendly: Yes
Stage: Discuss
