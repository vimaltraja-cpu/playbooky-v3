# Journey Map

Best Used When: The team needs to understand user behaviour, friction, drop-off, or experience gaps.
Duration: 60 mins
Facilitator Notes: Focus on the current experience before discussing solutions.

Use evidence wherever possible.

Encourage participants from different disciplines to contribute.

Pay particular attention to moments of confusion, frustration and drop-off.
Inputs Required: Analytics, Existing research, User feedback
Outputs Produced: Insights, Journey map
Purpose: Map the user or customer experience from start to finish.
Remote Friendly: Yes
Stage: Understand
