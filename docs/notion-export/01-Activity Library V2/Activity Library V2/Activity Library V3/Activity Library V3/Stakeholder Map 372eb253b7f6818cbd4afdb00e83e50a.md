# Stakeholder Map

Best Used When: The team needs to understand who is involved, affected, or influential.
Duration: 60 mins
Facilitator Notes: Encourage participants to consider both obvious and hidden stakeholders.

Look for conflicting incentives.

Use the exercise to identify engagement risks and opportunities.
Inputs Required: Stakeholders, Team context
Outputs Produced: Alignment, Insights
Purpose: Identify stakeholders, influence, needs, and relationships.
Remote Friendly: Yes
Stage: Understand
