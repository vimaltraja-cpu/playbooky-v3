# Workshop OS - Test Scenarios

## Purpose

This document is used to validate the Workshop OS diagnosis engine and workshop generation engine.

The goal is to test whether Workshop OS can:

- Correctly diagnose a challenge
- Identify the appropriate Primary Stage
- Identify the appropriate Secondary Stage
- Select suitable activities
- Generate a workshop that a facilitator would realistically run

These scenarios should be used whenever changes are made to:

- Diagnosis Logic
- Workshop Design Logic
- Activity Library
- Workshop Generation

---

# Scenario 1 - Discovery

## Challenge

A new onboarding experience has been launched.

Conversion has dropped.

The team does not understand why.

No formal research has been conducted.

Several assumptions exist but there is little evidence available.

## Desired Outcome

Understand what is happening.

Identify potential causes.

Create a clear problem statement.

## Constraints

90 minutes

8 participants

Remote

Cross-functional team

## Expected Diagnosis

Primary Stage:

Understand

Secondary Stage:

Frame

## Expected Activities

Journey Map

Five Whys

Problem Statement

## Success Criteria

The workshop produces:

- Shared understanding
- Key insights
- Defined problem statement

# Validation Process

For each scenario evaluate:

## Diagnosis Accuracy

Did Workshop OS identify the correct Primary Stage?

Did Workshop OS identify the correct Secondary Stage?

## Activity Selection

Were the selected activities appropriate?

Did the activities support the desired outcome?

## Workshop Quality

Would a facilitator realistically run this workshop?

Did the workshop feel coherent and connected?

Did outputs flow naturally between activities?

## Improvement Opportunities

What activities were missing?

What metadata was missing?

What diagnosis rules need refinement?

What workshop design rules need refinement?

---

# Success Metric

Workshop OS should consistently generate workshops that an experienced facilitator would be comfortable running without significant manual redesign.

The goal is not to generate perfect workshops.

The goal is to generate workshops that provide a strong starting point and require minimal adjustment before facilitation.
