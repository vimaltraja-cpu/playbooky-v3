# Capture Start Stop Continue Items

Duration: 15
Facilitator Notes: Encourage participants to think independently before discussing ideas.

Focus on behaviours, processes and ways of working.
Instructions: Ask participants to individually generate items for:

Start
Stop
Continue

Capture all contributions before discussion begins.
