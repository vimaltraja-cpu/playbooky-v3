# Define the Problem

Duration: 5
Facilitator Notes: Spend time clarifying the problem if needed.

A poorly defined problem will lead to poor root-cause analysis.

Focus on observable issues rather than assumptions about causes.
Instructions: Present the problem statement to the group.

Review any relevant evidence, examples or observations.

Ensure everyone agrees on the problem being explored before moving on.

Capture the final wording of the problem so it remains visible throughout the activity.
Parent Block: Five Whys (https://app.notion.com/p/Five-Whys-373eb253b7f68085bcc4f82ab630e055?pvs=21)
Purpose: Create a shared understanding of the problem that will be explored during the activity.
