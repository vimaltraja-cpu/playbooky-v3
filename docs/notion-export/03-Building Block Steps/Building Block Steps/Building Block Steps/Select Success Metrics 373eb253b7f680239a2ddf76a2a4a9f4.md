# Select Success Metrics

Duration: 5
Facilitator Notes: Limit the final selection to a small number of metrics.

Focus on quality and relevance rather than quantity.

The chosen metrics should be understandable and measurable.
Instructions: Review the grouped metrics.

Ask participants to independently vote for the metrics they believe best represent progress towards the objective.

Reveal votes simultaneously.

Select the highest scoring metrics for the next step.
Parent Block: Objectives and Key Results (OKRs) (https://app.notion.com/p/Objectives-and-Key-Results-OKRs-373eb253b7f68077acd4f9dbe3b761bc?pvs=21)
Purpose: Identify the most meaningful metrics that will become Key Results.
Step Order: 7
Technique Used: Blind Vote (https://app.notion.com/p/Blind-Vote-373eb253b7f680fdb80effd9c0fd2384?pvs=21)
