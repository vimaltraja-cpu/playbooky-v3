# Theme Sort Objectives

Duration: 10
Facilitator Notes: Avoid naming themes too early.

Focus on patterns and relationships rather than perfect categorisation.
Instructions: Ask participants to group similar objectives together.

Discuss emerging themes and identify overlaps.

Create labels for each cluster once patterns begin to emerge.
Parent Block: Objectives and Key Results (OKRs) (https://app.notion.com/p/Objectives-and-Key-Results-OKRs-373eb253b7f68077acd4f9dbe3b761bc?pvs=21)
Purpose: Group similar objectives together and identify common themes.
Step Order: 3
Technique Used: Theme Sort (https://app.notion.com/p/Theme-Sort-373eb253b7f680a79694c82252566fab?pvs=21)
