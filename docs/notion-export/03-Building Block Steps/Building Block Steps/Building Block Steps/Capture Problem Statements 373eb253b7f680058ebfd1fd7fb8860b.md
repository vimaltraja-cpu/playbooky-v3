# Capture Problem Statements

Duration: 10
Facilitator Notes: Keep participants focused on the problem.

Do not allow solution statements.

Individual thinking before discussion usually produces better results.
Instructions: Ask participants to individually write their version of the problem statement.

Encourage concise statements.

Capture all responses before discussing them.
Parent Block: Problem Statement (https://app.notion.com/p/Problem-Statement-373eb253b7f680faa68af78e68f8ce42?pvs=21)
Purpose: Generate multiple perspectives on what the problem actually is.
Step Order: 2
