# Create Key Results

Duration: 5
Facilitator Notes: Avoid vague targets.

Push for measurable and time-bound outcomes.

Challenge targets that are either unrealistic or too easy to achieve.
Instructions: Review each selected metric.

Turn each metric into a measurable target.

Capture the baseline if known and define a target outcome.

Ensure each Key Result can be objectively measured.
Parent Block: Objectives and Key Results (OKRs) (https://app.notion.com/p/Objectives-and-Key-Results-OKRs-373eb253b7f68077acd4f9dbe3b761bc?pvs=21)
Purpose: Convert selected metrics into measurable Key Results.
