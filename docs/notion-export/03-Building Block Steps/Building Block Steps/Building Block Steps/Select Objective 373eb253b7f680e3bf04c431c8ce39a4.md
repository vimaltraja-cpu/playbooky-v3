# Select Objective

Duration: 10
Facilitator Notes: Avoid debate before voting.

Blind voting helps reduce hierarchy and groupthink.

The objective is alignment, not unanimity.
Instructions: Review the objective themes.

Allow participants a short period to reflect independently.

Run a blind vote.

Reveal results simultaneously.

If there is no clear outcome, facilitate a short discussion and conduct a second round of voting.
Parent Block: Objectives and Key Results (OKRs) (https://app.notion.com/p/Objectives-and-Key-Results-OKRs-373eb253b7f68077acd4f9dbe3b761bc?pvs=21)
Purpose: Select a single objective that the group believes should be the primary focus.
Step Order: 4
Technique Used: Blind Vote (https://app.notion.com/p/Blind-Vote-373eb253b7f680fdb80effd9c0fd2384?pvs=21)
