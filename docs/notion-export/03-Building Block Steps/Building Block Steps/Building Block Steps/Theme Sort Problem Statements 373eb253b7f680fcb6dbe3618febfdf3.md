# Theme Sort Problem Statements

Duration: 15
Facilitator Notes: Look for patterns rather than perfect wording.

Avoid jumping to conclusions too early.

The goal is to understand how the group views the challenge.
Instructions: Group similar problem statements together.

Identify recurring themes.

Discuss similarities and differences.

Create labels for each cluster.
