# Theme Sort Metrics

Duration: 5
Facilitator Notes: Focus on clarity and relevance.

Do not spend time debating exact numbers at this stage.
Instructions: Group similar metrics into clusters.

Remove duplicates.

Identify common themes and discuss which measures best indicate progress.
Parent Block: Objectives and Key Results (OKRs) (https://app.notion.com/p/Objectives-and-Key-Results-OKRs-373eb253b7f68077acd4f9dbe3b761bc?pvs=21)
Purpose: Group similar metrics together and identify the strongest indicators of success.
Step Order: 6
Technique Used: Theme Sort (https://app.notion.com/p/Theme-Sort-373eb253b7f680a79694c82252566fab?pvs=21)
