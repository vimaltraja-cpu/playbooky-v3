# Draft Problem Statements

Duration: 10
Facilitator Notes: Challenge vague language.

Ensure statements describe the problem rather than the solution.

Encourage participants to use evidence gathered earlier in the activity.
Instructions: Using the themes identified, ask participants to draft candidate problem statements.

Aim for clear, concise and evidence-based statements.

Capture all drafts before evaluating them.
Parent Block: Problem Statement (https://app.notion.com/p/Problem-Statement-373eb253b7f680faa68af78e68f8ce42?pvs=21)
Purpose: Create a small number of candidate problem statements based on the themes identified.
