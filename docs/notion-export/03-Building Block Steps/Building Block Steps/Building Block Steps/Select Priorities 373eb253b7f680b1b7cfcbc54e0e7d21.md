# Select Priorities

Duration: 5
Facilitator Notes: Use voting to reduce bias and create transparency.

Focus on reaching alignment rather than achieving a perfect ranking.
Instructions: Review the prioritised opportunities.

Ask participants to vote independently.

Reveal votes simultaneously.

Select the highest-priority opportunities.
Parent Block: Priority Map (https://app.notion.com/p/Priority-Map-373eb253b7f6802eb4fae1026a89a2c8?pvs=21)
Purpose: Align on the opportunities that should move forward.
Step Order: 5
Technique Used: Blind Vote (https://app.notion.com/p/Blind-Vote-373eb253b7f680fdb80effd9c0fd2384?pvs=21)
