# Select Problem Statement

Duration: 5
Facilitator Notes: The goal is alignment, not perfection.

If two statements are very similar, consider merging them before voting.

Capture the final agreed problem statement clearly and visibly.
Instructions: Review the shortlisted problem statements.

Ask participants to independently vote for the statement they believe best represents the challenge.

Reveal votes simultaneously.

Select the winning statement or run a second round if needed.
