# Workshop OS MVP Flow

# Workshop OS - MVP Flow

## Goal

Help Product Managers and Product Designers move from a problem statement to a workshop recommendation, workshop plan, recommended decisions and action plan.

---

# Screen 1 — Dashboard

User arrives at Workshop OS.

Actions:

- Create New Workshop
- View Previous Workshops
- Browse Workshop Templates

Primary CTA:

Create Workshop

---

# Screen 2 — Define Challenge

User enters:

Problem Statement

Example:

"Users are confused about bonus eligibility and support tickets are increasing."

Problem Signals

Examples:

- Users are confused
- Support tickets increasing
- Customer expectations not met

Participants

Examples:

- Product
- Design
- Engineering
- Support

Desired Outcome

Examples:

- Understand problem
- Align stakeholders
- Define MVP
- Prioritise opportunities

CTA:

Generate Recommendation

---

# Screen 3 — Recommendation Engine

Workshop OS evaluates the problem signals.

Decision Engine identifies:

Recommended Workshop

Example:

Journey Mapping Workshop

Recommended Framework

Example:

Reality Gap Framework

Reasoning

Users are confused and support tickets are increasing, indicating a gap between customer expectations and actual system behaviour.

CTA:

Generate Workshop Plan

---

# Screen 4 — Workshop Plan

Workshop OS retrieves:

Workshop Type

Journey Mapping Workshop

Framework

Reality Gap Framework

Activities

- Journey Stage Mapping
- Pain Point Identification
- Root Cause Exploration
- Opportunity Mapping
- Solution Exploration
- Recommendation Creation

Generated Output

- Workshop Agenda
- Facilitation Guide
- Expected Outputs

CTA:

Start Workshop

---

# Screen 5 — Workshop Outputs

After the workshop, Workshop OS generates:

Findings

Pain Points

Root Causes

Opportunities

Recommended Decisions

Action Plan

Success Metrics

CTA:

Export

---

# End State

User leaves with:

- Recommended Workshop
- Recommended Framework
- Workshop Agenda
- Recommended Decisions
- Action Plan

Without needing to know which workshop to run or how to structure it.

---

# MVP Success Criteria

A user can move from:

Problem

↓

Workshop Recommendation

↓

Workshop Plan

↓

Recommended Decisions

↓

Action Plan

within 10 minutes.
