# Blind Vote

Block Type: Technique
Building Block Steps 1: Select Objective (https://app.notion.com/p/Select-Objective-373eb253b7f680e3bf04c431c8ce39a4?pvs=21), Select Success Metrics (https://app.notion.com/p/Select-Success-Metrics-373eb253b7f680239a2ddf76a2a4a9f4?pvs=21), Select Problem Statement (https://app.notion.com/p/Select-Problem-Statement-373eb253b7f6809287b8c7c30dd651fe?pvs=21), Select Opportunity Areas (https://app.notion.com/p/Select-Opportunity-Areas-373eb253b7f680c19a3dc89c24a23dd4?pvs=21), Select Priorities (https://app.notion.com/p/Select-Priorities-373eb253b7f680d5af5efa0f75b8c1e8?pvs=21), Select Priorities (https://app.notion.com/p/Select-Priorities-373eb253b7f680b1b7cfcbc54e0e7d21?pvs=21), Select Priorities (https://app.notion.com/p/Select-Priorities-373eb253b7f680dd9efdcbeba4268f7b?pvs=21)
Energy Level: Reflective
Facilitator Notes: Do not allow participants to discuss their choices before voting.

Ensure everyone understands the options and criteria.

Ask participants to vote independently.

Reveal all votes at the same time.

Use discussion only after votes have been revealed.

If there is no clear outcome, run a second round or use the result to focus the next discussion.

Blind Vote is designed to reduce bias and create a more honest view of group opinion.
Inputs: Assumptions, Decision needed, Ideas, Objective, Opportunities, Problem statement, Risks
Outcomes: Alignment, Commitment, Consensus, Decision making
Outputs: Decision, Prioritised list
Preparation Needed: Clearly define what is being voted on.

Ensure all options are visible and understood by participants.

Decide voting criteria before starting.

Prepare a method for collecting votes simultaneously.
Purpose: Allow participants to make independent decisions without being influenced by dominant voices, hierarchy or groupthink.
Stage: Decide, Discuss, Evaluate, Frame, Goals
Typical Duration: 5
Workshop Design Logic: Need Alignment On Options (https://app.notion.com/p/Need-Alignment-On-Options-373eb253b7f68072af94f366acff2d47?pvs=21)
