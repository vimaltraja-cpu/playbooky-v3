# Start Stop Continue

Block Type: Hybrid
Building Block Steps: Review Context (https://app.notion.com/p/Review-Context-373eb253b7f6802b9997e3ca5f9d6d41?pvs=21), Capture Start Stop Continue Items (https://app.notion.com/p/Capture-Start-Stop-Continue-Items-373eb253b7f68011a64cfc0f136ccac6?pvs=21), Theme Sort Responses (https://app.notion.com/p/Theme-Sort-Responses-373eb253b7f680a09506dff16504131e?pvs=21), Review & Refine Themes (https://app.notion.com/p/Review-Refine-Themes-373eb253b7f680e5a1e2d334d54e3bab?pvs=21), Select Priorities (https://app.notion.com/p/Select-Priorities-373eb253b7f680dd9efdcbeba4268f7b?pvs=21), Commit Actions (https://app.notion.com/p/Commit-Actions-373eb253b7f6808ba72bce32c58085bf?pvs=21)
Energy Level: Collaborative
Facilitator Notes: Focus on behaviours, processes and ways of working rather than individuals.

Encourage constructive feedback.

Look for recurring themes and patterns.

Finish by agreeing which actions will be taken forward.
Inputs: Current state, Team context
Outcomes: Action planning, Alignment, Shared understanding, Team alignment
Outputs: Action plan, Insights, Next steps
Preparation Needed: Prepare three areas labelled:

Start
Stop
Continue

Ensure participants understand the topic being reviewed before beginning the activity.
Purpose: Reflect on current behaviours, processes or ways of working and identify what should start, stop or continue.
Stage: Discuss, Evaluate
Typical Duration: 65
Workshop Design Logic: Need Team Reflection (https://app.notion.com/p/Need-Team-Reflection-373eb253b7f680d0b9cdcaac88de441e?pvs=21)
Workshop Design Logic 1: No Clear Goal (https://app.notion.com/p/No-Clear-Goal-373eb253b7f680679289e41572ad6c89?pvs=21), Need Clear Priorities (https://app.notion.com/p/Need-Clear-Priorities-373eb253b7f680699ca6e1164113ab4a?pvs=21)
