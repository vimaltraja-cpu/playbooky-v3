# Five Whys

Block Type: Hybrid
Building Block Steps: Define the Problem (https://app.notion.com/p/Define-the-Problem-373eb253b7f6806f9bade3e1c431c9ec?pvs=21), Why #1 (https://app.notion.com/p/Why-1-373eb253b7f6802e85e6f36b0293a4b5?pvs=21), Why #2 (https://app.notion.com/p/Why-2-373eb253b7f6807a9fe6cd17a091e14b?pvs=21), Why #3 (https://app.notion.com/p/Why-3-373eb253b7f680ff87bdf12ea74fa1e9?pvs=21), Why #4 (https://app.notion.com/p/Why-4-373eb253b7f6801bbdb8cd1a10a50f3d?pvs=21), Why #5 (https://app.notion.com/p/Why-5-373eb253b7f68070a50bfe7ee66c6097?pvs=21), Review Root Causes (https://app.notion.com/p/Review-Root-Causes-373eb253b7f68082b607fde30b9cf800?pvs=21), Define Next Steps (https://app.notion.com/p/Define-Next-Steps-373eb253b7f68081b712f15bcf8e300b?pvs=21)
Energy Level: Reflective
Facilitator Notes: Focus on understanding the system rather than assigning blame.

Do not force exactly five rounds.

Stop when the group reaches a meaningful root cause that they can influence.

If multiple causes emerge, capture them separately rather than forcing a single answer.
Inputs: Problem, Problem statement
Outcomes: Problem clarity, Root cause discovery, Shared understanding
Outputs: Insights, Root causes
Preparation Needed: Start with a clearly defined problem statement.

Prepare space to capture each why and the corresponding answer.
Purpose: Explore the underlying causes of a problem by repeatedly asking why it is occurring.
Stage: Frame, Understand
Typical Duration: 45
Workshop Design Logic: Root Cause Unknown (https://app.notion.com/p/Root-Cause-Unknown-373eb253b7f6806ca980c6417819de7c?pvs=21)
