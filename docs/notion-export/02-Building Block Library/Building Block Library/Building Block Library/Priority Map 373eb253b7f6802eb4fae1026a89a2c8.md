# Priority Map

Block Type: Hybrid
Building Block Steps: Review Opportunities (https://app.notion.com/p/Review-Opportunities-373eb253b7f68073b3dbdc765de950fa?pvs=21), Define Prioritisation Criteria (https://app.notion.com/p/Define-Prioritisation-Criteria-373eb253b7f68051a773f95489322397?pvs=21), Map Priorities (https://app.notion.com/p/Map-Priorities-373eb253b7f680b3bc4be9ccee7867b7?pvs=21), Review Priority Groups (https://app.notion.com/p/Review-Priority-Groups-373eb253b7f680b59193d5a5c50fa515?pvs=21), Select Priorities (https://app.notion.com/p/Select-Priorities-373eb253b7f680b1b7cfcbc54e0e7d21?pvs=21), Commit Actions (https://app.notion.com/p/Commit-Actions-373eb253b7f68018beeed74bcf8bc49b?pvs=21)
Energy Level: Collaborative
Facilitator Notes: Make the prioritisation criteria explicit before starting.

Challenge opinions that are not supported by evidence.

Focus on creating agreement around what should happen next rather than creating a perfect ranking.

Use voting techniques if the group becomes stuck.
Inputs: Decision needed, Ideas, Opportunities
Outcomes: Alignment, Decision making, Prioritisation
Outputs: Decision, Prioritised list
Preparation Needed: Prepare a prioritisation framework and agree the decision criteria before the session begins.

Ensure all options are visible and understood by participants.
Purpose: Help teams compare options and agree what should be prioritised first.
Stage: Decide, Evaluate
Typical Duration: 45
