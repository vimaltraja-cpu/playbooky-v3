# Who, What, When

Block Type: Technique
Building Block Steps 1: Review and Commit (https://app.notion.com/p/Review-and-Commit-373eb253b7f680c89c53cc5ed21a45a3?pvs=21), Define Next Steps (https://app.notion.com/p/Define-Next-Steps-373eb253b7f68081b712f15bcf8e300b?pvs=21), Confirm Recommendations (https://app.notion.com/p/Confirm-Recommendations-373eb253b7f6809184f0c927bd154c5b?pvs=21), Commit Actions (https://app.notion.com/p/Commit-Actions-373eb253b7f68018beeed74bcf8bc49b?pvs=21), Commit Actions (https://app.notion.com/p/Commit-Actions-373eb253b7f6808ba72bce32c58085bf?pvs=21)
Energy Level: Reflective
Facilitator Notes: Push for specific actions rather than vague intentions.

Every action should have a named owner and a clear deadline.

Avoid assigning actions to groups or teams.

Focus on commitment and accountability.
Inputs: Actions, Decision needed, Ideas, Opportunities
Outcomes: Action planning, Commitment, Owernship
Outputs: Action plan, Next steps, Owership
Preparation Needed: Prepare a simple structure with three columns:

Who
What
When

Ensure decisions or actions have already been identified before running this technique.
Purpose: Turn decisions, ideas or recommendations into clear actions with ownership and accountability.
Stage: Decide, Discuss
Typical Duration: 15
