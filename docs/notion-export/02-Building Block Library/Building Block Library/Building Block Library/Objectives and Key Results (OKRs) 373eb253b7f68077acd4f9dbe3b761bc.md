Facilitator Notes: Push the group towards a single objective rather than multiple competing priorities.

Challenge vague objectives and encourage measurable key results.

Focus on outcomes rather than outputs.

Use voting when alignment cannot be reached through discussion.

Outcomes: Alignment, Success measurement, goal setting
Outputs: Key results, Objective, Success metrics
Preparation Needed: Create alignment around a shared objective and define measurable indicators of success.
