# Impact Effort Map

Block Type: Hybrid
Building Block Steps: Review Opportunities (https://app.notion.com/p/Review-Opportunities-373eb253b7f680b9a079f690bccb4c88?pvs=21), Create Impact Effort Matrix (https://app.notion.com/p/Create-Impact-Effort-Matrix-373eb253b7f68096bfa6e41963a6fd5d?pvs=21), Map Opportunities (https://app.notion.com/p/Map-Opportunities-373eb253b7f680679992f6a67e79fda1?pvs=21), Review Opportunity Clusters (https://app.notion.com/p/Review-Opportunity-Clusters-373eb253b7f6805b93efe5f70b4eb31a?pvs=21), Select Priorities (https://app.notion.com/p/Select-Priorities-373eb253b7f680d5af5efa0f75b8c1e8?pvs=21), Confirm Recommendations (https://app.notion.com/p/Confirm-Recommendations-373eb253b7f6809184f0c927bd154c5b?pvs=21)
Energy Level: Collaborative
Facilitator Notes: Focus on relative comparison rather than trying to score items perfectly.

Challenge assumptions about effort and impact.

Use discussion to resolve major disagreements but avoid over-analysing individual items.

The goal is to identify which opportunities should be pursued first.
Inputs: Ideas, Opportunities
Outcomes: Alignment, Decision making, Prioritisation
Outputs: Decision, Prioritised list
Preparation Needed: Prepare a matrix with two axes:

Impact
Effort

Ensure participants understand the evaluation criteria before placing items on the map.
Purpose: Evaluate opportunities, ideas or actions by comparing their expected impact against the effort required to deliver them.
Stage: Decide, Evaluate
Typical Duration: 45
