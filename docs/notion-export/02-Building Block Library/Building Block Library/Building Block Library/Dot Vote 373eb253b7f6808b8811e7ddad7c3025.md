# Dot Vote

Block Type: Technique
Energy Level: Reflective
Facilitator Notes: Dot voting is best used to identify preferences, not make final decisions.

Ask participants to vote silently.

Review results as a group and discuss any surprising outcomes.

If required, use Blind Vote afterwards to make a final decision.
Inputs: Assumptions, Ideas, Opportunities
Outcomes: Consensus, Prioritisation
Outputs: Prioritised list
Preparation Needed: Display all options clearly and ensure participants understand the voting criteria.

Decide how many votes each participant receives before starting.
Purpose: Quickly identify group preferences by allowing participants to distribute votes across multiple options.
Stage: Decide, Evaluate
Typical Duration: 10
