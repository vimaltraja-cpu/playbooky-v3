# Theme Sort

Block Type: Technique
Building Block Steps 1: Theme Sort Objectives (https://app.notion.com/p/Theme-Sort-Objectives-373eb253b7f680a29a6af11711ee47c2?pvs=21), Theme Sort Metrics (https://app.notion.com/p/Theme-Sort-Metrics-373eb253b7f680a9bbf7e7da82073643?pvs=21), Theme Sort Problem Statements (https://app.notion.com/p/Theme-Sort-Problem-Statements-373eb253b7f680fcb6dbe3618febfdf3?pvs=21), Theme Sort Opportunities (https://app.notion.com/p/Theme-Sort-Opportunities-373eb253b7f680eaa68bd6345e1966b2?pvs=21), Review Opportunity Clusters (https://app.notion.com/p/Review-Opportunity-Clusters-373eb253b7f6805b93efe5f70b4eb31a?pvs=21), Review Priority Groups (https://app.notion.com/p/Review-Priority-Groups-373eb253b7f680b59193d5a5c50fa515?pvs=21), Theme Sort Responses (https://app.notion.com/p/Theme-Sort-Responses-373eb253b7f680a09506dff16504131e?pvs=21)
Energy Level: Reflective
Facilitator Notes: Encourage participants to move notes silently before discussing.

Focus on identifying natural patterns rather than forcing categories.

Avoid naming themes too early.

When clusters begin to emerge, ask participants what connects the items.

Once clusters stabilise, create clear labels that describe the theme.

The goal is not organisation for its own sake. The goal is shared understanding.
Inputs: Assumptions, Ideas, Insights, Opportunities, Research, Stakeholders, User feedback
Outcomes: Alignment, Opportunity discovery, Problem clarity, Shared understanding
Outputs: Insights, Themes
Preparation Needed: Prepare a board or workspace where notes can be moved freely.

Ensure participants have already generated or collected information to sort.

Theme Sort works best after idea generation, research review or information gathering activities.
Purpose: Group similar ideas, observations or pieces of information into meaningful themes to reveal patterns and support discussion.
Stage: Discuss, Evaluate, Frame, Ideas, Understand
Typical Duration: 15
