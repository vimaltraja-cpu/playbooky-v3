# Parking Lot

Block Type: Technique
Energy Level: Reflective
Facilitator Notes: Use the Parking Lot whenever discussions drift away from the workshop objective.

Acknowledge the contribution, capture it visibly and return focus to the current activity.

Review the Parking Lot before the workshop closes and decide whether items require actions, follow-up discussions or can be discarded.
Inputs: Ideas, Risks
Outcomes: Action planning, Alignment
Outputs: Next steps, Risks
Preparation Needed: Create a clearly visible Parking Lot section on the workshop board before the session begins.
Purpose: Capture off-topic questions, risks or ideas without derailing the workshop.
Stage: Decide, Discuss
Typical Duration: 5
