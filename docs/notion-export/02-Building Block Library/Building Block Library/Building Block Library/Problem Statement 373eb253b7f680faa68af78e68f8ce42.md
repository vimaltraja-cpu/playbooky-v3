# Problem Statement

Block Type: Activity
Building Block Steps: Review Context & Evidence (https://app.notion.com/p/Review-Context-Evidence-373eb253b7f680b09a49df44ae4f067a?pvs=21), Capture Problem Statements (https://app.notion.com/p/Capture-Problem-Statements-373eb253b7f680058ebfd1fd7fb8860b?pvs=21), Theme Sort Problem Statements (https://app.notion.com/p/Theme-Sort-Problem-Statements-373eb253b7f680fcb6dbe3618febfdf3?pvs=21), Draft Problem Statements (https://app.notion.com/p/Draft-Problem-Statements-373eb253b7f68045a110e69eb3225ab1?pvs=21), Refine & Consolidate (https://app.notion.com/p/Refine-Consolidate-373eb253b7f680cb84b5ea98a3c9bbf8?pvs=21), Select Problem Statement (https://app.notion.com/p/Select-Problem-Statement-373eb253b7f6809287b8c7c30dd651fe?pvs=21)
Energy Level: Collaborative
Facilitator Notes: Keep the group focused on the problem rather than solutions.

Challenge assumptions and vague language.

A good problem statement should be specific, evidence-based and understandable by everyone in the room.
Inputs: Insights, Problem, Research, User feedback
Outcomes: Alignment, Problem clarity, Shared understanding
Outputs: Problem statement
Preparation Needed: Gather research, insights and evidence related to the challenge.

Ensure participants have enough context to discuss the problem before beginning.
Purpose: Create a clear and shared understanding of the problem that needs to be solved.
Stage: Frame
Typical Duration: 60
Workshop Design Logic: Problem Not Clearly Defined (https://app.notion.com/p/Problem-Not-Clearly-Defined-373eb253b7f680019328c3e34797c2e7?pvs=21)
