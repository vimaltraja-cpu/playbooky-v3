# How Might We

Block Type: Activity
Building Block Steps: Review Problem Statement (https://app.notion.com/p/Review-Problem-Statement-373eb253b7f680a4aea5c7befa2ea62f?pvs=21), Generate How Might We Statements (https://app.notion.com/p/Generate-How-Might-We-Statements-373eb253b7f6804e8ebcc09624c491be?pvs=21), Theme Sort Opportunities (https://app.notion.com/p/Theme-Sort-Opportunities-373eb253b7f680eaa68bd6345e1966b2?pvs=21), Refine Opportunity Areas (https://app.notion.com/p/Refine-Opportunity-Areas-373eb253b7f680d2a066dfb19ce54f95?pvs=21), Select Opportunity Areas (https://app.notion.com/p/Select-Opportunity-Areas-373eb253b7f680c19a3dc89c24a23dd4?pvs=21)
Energy Level: Energetic
Facilitator Notes: Avoid writing How Might We statements that already contain a solution.

Encourage participants to generate multiple statements before discussing them.

Keep questions broad enough to inspire creativity but focused enough to remain relevant to the challenge.
Inputs: Ideas, Opportunities
Outcomes: Idea generation, Opportunity discovery
Outputs: Ideas, Opportunities
Preparation Needed: Prepare a clear problem statement.

Ensure participants understand the challenge before beginning.

Create space to capture multiple How Might We statements and resulting ideas.
Purpose: Reframe problems into opportunity-focused questions that encourage solution exploration.
Stage: Frame, Ideas
Typical Duration: 40
Workshop Design Logic: Need More Ideas (https://app.notion.com/p/Need-More-Ideas-373eb253b7f680f6aeadee21868cf25f?pvs=21)
Workshop Design Logic 1: No Clear Goal (https://app.notion.com/p/No-Clear-Goal-373eb253b7f680679289e41572ad6c89?pvs=21), Problem Not Clearly Defined (https://app.notion.com/p/Problem-Not-Clearly-Defined-373eb253b7f680019328c3e34797c2e7?pvs=21)
