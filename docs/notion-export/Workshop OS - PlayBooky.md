# Workshop OS - PlayBooky

Workshop OS is an AI Workshop Designer.

Users do not select workshops.

Users describe their challenge, desired outcome and constraints.

Workshop OS diagnoses the situation, identifies the current stage, selects appropriate activities and generates a bespoke workshop agenda.

The output is a workshop designed specifically for the user's context rather than a predefined template.

Stages:

- Goals
- Understand
- Frame
- Ideas
- Evaluate
- Decide
- Discuss

Activities are modular building blocks.

Recipes and workshop templates are reference patterns, not fixed outputs.

The primary value of Workshop OS is diagnosis and workshop generation.
