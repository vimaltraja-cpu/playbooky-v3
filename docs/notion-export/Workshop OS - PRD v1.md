# Workshop OS - PRD v1

## Vision

Workshop OS helps Product Managers and Product Designers move from ambiguity to aligned decisions and actionable plans.

By combining workshop recommendations, facilitation frameworks and AI-generated outputs, Workshop OS helps teams identify the right workshop, run it effectively and turn findings into decisions.

---

# Problem

Product teams frequently struggle with:

- Stakeholder misalignment
- Unclear problem definition
- Hidden dependencies
- Prioritisation challenges
- Scope creep
- Difficulty turning workshop outputs into actions

While workshops are commonly used, there is little guidance on:

- Which workshop to run
- Which framework to use
- How to facilitate effectively
- How to turn outputs into decisions

# Core User Journey

1. Define Challenge

User describes:

- Problem statement
- Problem signals
- Participants
- Desired outcome
1. Generate Recommendation

Workshop OS recommends:

- Workshop Type
- Framework
- Activities
1. Generate Workshop Plan

Workshop OS generates:

- Workshop agenda
- Facilitation guide
- Expected outputs
1. Run Workshop

User runs workshop using generated plan.

1. Generate Outputs

Workshop OS generates:

- Findings summary
- Recommended decisions
- Action plan
- Success metrics
