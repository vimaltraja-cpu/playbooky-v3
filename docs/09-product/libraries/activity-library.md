# Purpose

The Activity Library is the canonical collection of facilitation activities used throughout PlayBooky.

Each activity represents a reusable facilitation exercise designed to achieve a specific workshop outcome.

Activities are the fundamental building blocks used to construct workshops.

Rather than creating bespoke workshops from scratch, PlayBooky assembles workshops by selecting, sequencing and configuring activities from the Activity Library.

---

# What is an Activity?

An Activity is a structured facilitation exercise that helps participants achieve a specific outcome within a workshop.

Activities are designed to be:

- Reusable
- Independent
- Outcome driven
- Facilitation focused
- Configurable
- Compatible with multiple workshop types

An activity is never tied to a single workshop.

The same activity may appear in many different workshops depending on the recommendation generated by the Decision Engine.

---

# Responsibilities

The Activity Library is responsible for:

- Storing reusable facilitation activities.
- Defining activity metadata.
- Supporting recommendation generation.
- Supporting workshop generation.
- Providing facilitator guidance.
- Providing AI prompt references.
- Linking activities to frameworks and workshop types.

The Activity Library does not determine which activities should be used.

Activity selection is the responsibility of the Decision Engine.

# Design Principles

The Activity Library follows these principles.

- Activities are reusable.
- Activities remain independent from workshop structure.
- Activities should be outcome focused.
- Activities should support multiple frameworks.
- Activities should support multiple workshop types.
- Activity content should exist in one canonical source.
- Activity metadata should be structured rather than duplicated.
