# Product System

The Product System documents how PlayBooky works.

Unlike the Design System, which defines how PlayBooky looks and behaves visually, the Product System defines how PlayBooky thinks, makes decisions, generates workshops and delivers facilitation experiences.

It provides the product architecture that connects diagnosis, recommendation, workshop generation and live facilitation into one coherent system.

Defines why PlayBooky exists, the problems it solves and the long-term direction of the platform.

---

### Product Architecture

Defines how the complete PlayBooky product works.

This is the canonical reference for understanding the relationship between every major product system.

## Relationship to the Design System

The Design System explains how PlayBooky looks.

The Product System explains how PlayBooky works.

Together they provide a complete blueprint for designing, building and evolving the PlayBooky platform.
