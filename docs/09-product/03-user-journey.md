# Purpose

This document describes the end-to-end PlayBooky user journey.

It explains how a user challenge is transformed into a facilitator-ready workshop through a series of connected product systems.

Unlike individual feature documentation, this document focuses on the complete experience rather than specific interfaces.

---

# Journey Overview

Every PlayBooky workshop follows the same high-level journey.

```text
Challenge

↓

Diagnosis

↓

Recommendation

↓

Workshop Design

↓

Workshop Build

↓

Facilitator Preparation

↓

Workshop Delivery
```

Each stage progressively transforms user input into a richer and more structured output.

---

# Stage 1 — Challenge

The user arrives with a problem they want to solve.

Typical examples include:

- Alignment
- Prioritisation
- Discovery
- Strategy
- Problem Solving
- Ideation

Output

• Challenge statement

---

# Stage 2 — Diagnosis

PlayBooky gathers structured information about the challenge.

Rather than asking users to browse workshop templates, the platform seeks to understand the nature of the problem.

Output

• Diagnostic responses

---

# Stage 3 — Recommendation

Diagnostic responses are analysed by the Diagnosis Engine and Decision Engine.

PlayBooky recommends the most appropriate workshop characteristics.

Output

• Framework
• Workshop Type
• Activity Recommendations

---

# Stage 4 — Workshop Design

Recommended activities are assembled into a coherent workshop structure.

Activities remain reusable building blocks and can be reordered or replaced.

Output

• Workshop draft

---

# Stage 5 — Workshop Build

The facilitator reviews and customises the workshop.

Activities, timings and sequencing can be refined.

Output

• Completed workshop

---

# Stage 6 — Facilitator Preparation

PlayBooky generates supporting guidance.

This includes facilitation prompts, timing guidance and delivery support.

Output

• Facilitator Guide

---

# Stage 7 — Workshop Delivery

The facilitator delivers the workshop using PlayBooky Live.

This is the operational experience used during live facilitation.

Output

• Delivered workshop

---

# Journey Principles

The PlayBooky journey is guided by the following principles.

- Start with the challenge, not the solution.
- Diagnose before recommending.
- Recommendations should always be explainable.
- Workshops are assembled rather than selected.
- Facilitators remain in control.
- Every stage should prepare the next stage.
